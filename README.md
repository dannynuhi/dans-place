# Dan's Place

Simple fixes. Clear answers.

Dan's Place is a local, zero-cost troubleshooting knowledge platform. It generates validated English and Spanish static pages, SEO metadata, JSON records, and sitemap files without paid APIs.

## Run

```sh
./build/run.sh
```

The generator writes all output under this project folder:

- `generated/html/`
- `generated/json/`
- `seo/sitemaps/`
- `seo/reports/`
- `logs/`
